# Machine-design sources

Original bundled prose is project content under `LGPL-2.1-or-later` unless a page
says otherwise. **Copy** or adapt externally authored content only when the
license covers that specific artifact; keep attribution, license/notice text,
source revision and change notices as required. Copies retain their source
license; the repository license does not replace it. **Link-only** means cite
and send the reader out, without importing substantial text, tables or figures.

Concept frontmatter `sources:` values **must** match an `id` below.
Prefer purchase/read + citation for ASME Y14.5, ISO 1101, and other standards; keep body text outside the corpus.
NonCommercial sources stay **link-only** for the application bundle. ShareAlike
and other copyleft licenses can permit commercial copying; preserve their
applicable terms and a compatible destination license rather than relabeling
copies as original LGPL prose.
